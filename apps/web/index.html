A few things
to know

Can I download a ready-to-install app?

There is no public installer yet. You can build the current foundation from source using the repository instructions and check GitHub Releases for future published builds.

Does the website run the desktop editor?

The image shows the browser preview of the workbench. Native folder access, disk saving, and agent subprocesses require the desktop app.

Which agents can I use?

The foundation connects local agents through ACP. Compatibility, distribution, and authentication depend on the agent. The repository describes registry support and custom executable configuration. Live provider verification is ongoing.

How are agent edits controlled?

span exposes permission requests and a review of proposed changes. Local agents run with your operating system user's access. Those editor controls do not sandbox the agent process.

Is span open source?

The project source is MIT licensed and available on GitHub. Supplied artwork, third-party logos, and icon assets retain their own provenance and applicable terms.
