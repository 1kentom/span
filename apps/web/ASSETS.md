Agent logos are copied from the application's SVGL collection. Source URLs and original metadata are retained in `assets/brands/provenance.json`, with the SVGL repository license in `assets/brands/LICENSE.svgl.txt`. Product names and trademarks belong to their respective owners. Their appearance identifies the ACP ecosystem and does not imply partnership, endorsement, or verified provider integration.

Language icons come from the application's Material Icon Theme collection, with its license in `assets/languages/LICENSE`. Interface icons come from the existing application Iconsax assets. Directional controls use the supplied pure chevrons.

The editor preview is a screenshot of the project's browser workbench. It is labelled as a browser preview and does not establish native runtime or provider verification.

The macOS and Windows platform symbols on the download page are extracted from the supplied reference Iconsax SVG definitions. The Linux symbol reuses the existing terminal icon to identify the platform without introducing another logo source.
